# TestGrafana

Scripts Python d'expérimentation autour de l'API Mistral et de l'insertion de données destinées à être visualisées dans Grafana.

## Stack

- Python, requests

## Contenu

- `main.py` — test d'appel à l'API Mistral (listing des modèles)
- `InsertionGrafana.py` — script d'insertion de données pour Grafana

## Note

Le script contient une clé d'API d'exemple à remplacer par la vôtre avant toute utilisation.
